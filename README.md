# WhatsApp Auto Messenger Bot

Node.js based WhatsApp automation bot — multi-session, bulk/scheduled messaging, group & channel management, welcome messages, number extraction, auto tagging, error reporting aur web dashboard.

## Status

🚧 **Planning stage.** Implementation phases ke liye [ROADMAP.md](./ROADMAP.md) dekhein — 37 features, 31 phases, 7 milestones.

## Planned Stack

- **Runtime:** Node.js 20 LTS (ESM)
- **WhatsApp:** Baileys (Multi-Device)
- **API:** Express + zod + JWT
- **DB:** Prisma → SQLite (dev) / Postgres (prod)
- **Queue:** BullMQ + Redis
- **Dashboard:** React + Vite + Tailwind
- **Ops:** PM2, Docker, GitHub Actions

## Disclaimer

Bulk aur unsolicited messaging WhatsApp ke Terms of Service ke against hai aur number ban ho sakta hai. Yeh project **opt-in audience, apne owned groups/channels aur consented contacts** ke liye hai. Use responsibly.
